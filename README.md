# Portfolio

Portfolio statique en `HTML/CSS/JavaScript` avec:

- page d'accueil en cards scrollables horizontalement
- couleurs basées sur fond noir
- page détail de projet au clic sur une card

## Fichiers

- `index.html`: accueil avec la liste des projets
- `project.html`: détail d'un projet
- `projects.js`: contenu des projets (titre, texte, technos, etc.)
- `script.js`: rendu dynamique des cards et de la page détail
- `styles.css`: design global
- `ressources/`: dossier pour tes images

## Personnalisation

1. Place tes images dans `ressources/`.
2. Modifie `projects.js`:
   - `image`: chemin de l'image
   - `title`, `summary`, `description`, `technologies`, `challenges`, `results`
   - `accent.color`: couleur de la card/projet
3. Ouvre `index.html` dans ton navigateur.
